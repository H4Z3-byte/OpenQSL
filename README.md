> [!NOTE]
> ### ⚠️ Nota importante sui messaggi nel Terminale / Prompt dei Comandi
> Durante l'uso o la fase di download, potresti notare alcuni messaggi di errore come **`FAILED`** o brevi disconnessioni nel terminale.
> 
> **Non preoccuparti, è un comportamento del tutto normale e previsto:** 
> L'applicazione integra un sistema automatico di *retry* (riprovas). In caso di errore temporaneo di rete o risposta lenta dai server, il programma continuerà a ritentare il download in background finché tutti i dati non saranno stati scaricati con successo.
